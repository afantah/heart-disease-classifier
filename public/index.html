Academic Architecture & Methodology

Supervised Classification Pipeline with One-Hot Categorical Encoding

This decision support system is trained on 500 clinical patient records. Per course guidelines, categorical clinical attributes are processed via One-Hot Encoding to prevent artificial ordinal hierarchy.

One-Hot Categorical Encoding

Nominal variables (sex, smoker, diabetes, family_history) are transformed into orthogonal binary dummy vectors using Scikit-Learn's OneHotEncoder(drop='first'), avoiding multicollinearity and dummy variable traps.

Standard Scaling

Continuous clinical vitals (age, blood_pressure, cholesterol, bmi, physical_activity, stress_level) are standardized using StandardScaler (μ=0, σ=1) to preserve numerical stability for gradient and distance calculations.

Rigorous Cross-Validation

Hyperparameters were tuned via 5-Fold Stratified Cross-Validation across 6 candidate algorithms (Gradient Boosting, Logistic Regression, Random Forest, SVM, KNN, Decision Tree), evaluated on a held-out 100-sample test set.
